A Game State Adjusted Corner Model

Beating Pinnacle corner markets by building corner ratings that see past the scoreline

Author

Luke Chambers

1. Introduction

Corner betting markets rate teams on how many corners they win and concede. But the number of corners a team takes depends a lot on the scoreline and on how strong the opponent is, and over a short run of fixtures those two things skew the raw counts. This project removes that bias by valuing every corner in the context it was won and builds team ratings from the adjusted values.

45 leagues modelled

139,172 matches

1.4m corner events valued

+2.1–4.1% handicap ROI, every tested rating set

Summary

  • Game state has a large effect on corners. In the median league, the home side’s share of corners is 16 points higher when losing than when winning.
  • Over short periods, teams spend much more or much less time winning or losing than their strength would suggest, so raw corner counts are a noisy measure of ability.
  • Valuing each corner by its game state, its home/away context and the pre-match supremacy, and dropping “repeater” corners, gives ratings that predict future corners better than raw counts do at every window length tested.
  • Against real Pinnacle prices, the adjusted ratings are profitable in the corner handicap market across all 8 rating sets tested. The best rating set had an ROI of 4.1% across 3,486 bets during the testing window. They show no edge in predicting corner totals.
  • The optimal ratings framework derived from this testing now powers an active betting model. An automated workflow scrapes upcoming fixtures, derives current team ratings, makes predictions and compares this to the current Pinnacle prices. These predictions are sent to a dashboard that shows me recommended bets each day.

2. The data

Two scrapers feed the model. Each runs automatically every day on GitHub Actions. The raw output is archived, and the processing stages read from there.

totalcorner.com: match events

The first scraper collects every finished match in 45 leagues from totalcorner.com. Each match has:

  • an event timeline: every goal, corner and card, with the minute it happened
  • full-time match stats: corners, shots on and off target, attacks, dangerous attacks and possession for each side
  • pre-match betting lines shown on the match page: the Asian handicap, goal line and corner line, with their odds

Results are stored in a local database and exported as one CSV per league. The same scraper also collects upcoming fixtures for the live model.

How it’s used. The timeline gives the scoreline at every minute of every match. From this we can work out how long each team spent winning, drawing and losing, and which game state each corner was won in. The pre-match handicap and goal lines are converted into each match’s expected goals and supremacy (the expected goal difference), a market-implied measure of the relative strength of each team.

Odds to expected goals and supremacy → code/odds_to_goals.py

Why it’s useful. Most corner data only gives team and match totals. That can’t tell you whether a team’s corners came while chasing a game or while protecting a lead. The minute-by-minute timeline is what makes the game-state adjustments possible, and its coverage of second-tier leagues means promoted and relegated teams can be tracked across divisions.

Pinnacle: corner market prices

The second scraper visits Pinnacle once a day and records prices for every fixture in the next seven days: match result, Asian handicap, goal line, and the two corner markets (corner handicap and corner totals). A processing step then removes Pinnacle’s margin and fits a Poisson distribution (totals) and a Skellam distribution (handicap) to find the implied corner total and supremacy.

The archive covers 21,798 matches scraped since August 2022.

How it’s used. Pinnacle’s corner supremacy is the benchmark the model has to beat. In the backtest, the model’s predicted supremacy is compared with Pinnacle’s for each match. When the two disagree by enough, a bet is placed at Pinnacle’s quoted odds and settled on the actual corners. In the live model, the same comparison flags value bets on upcoming fixtures.

Why it’s useful. Pinnacle is widely regarded as the sharpest bookmaker. It runs low margins, and is known for not restricting winning customers, so its prices are the best estimate of the “true” market view. Generally, a model that beats Pinnacle has found a real edge rather than just a soft bookmaker. It is also the only bookmaker I have an active account with so if I want to build a model that can be profitable in real time it will need to beat Pinnacle lines.

3. Data processing

The raw event data goes through three processing steps before any analysis: working out the game state at every event, adding up the minutes and corners each team had in each state, and flagging repeater corners.

Identifying game state at each match event

Each match’s events are processed in time order, keeping a running count of goals for each side. After every event the score gives the game state: 0 = drawing, 1 = home winning, 2 = away winning. Recording where the state changes marks the start and end of each spell of play at a given scoreline.

Minutes and corners in each game state

The total minutes each team spends in each game state is calculated using the previous table. Every corner is then counted under the game state it was won in, from the corner-taking team’s point of view.

Two checks remove corrupted matches: the minutes in each state must add up to the match length, and the corners in each state must add up to the scraped full-time total.

The result is one row per team per match. Three Premier League examples:

Supremacy is the market’s expected goal difference from each team’s point of view, so a positive number means the team was the pre-match favourite.

In all three matches, most of one team’s corners came in a short spell of winning or losing. Crystal Palace won 8 of their 9 corners in the 35 minutes they trailed Burnley, and only one in the 62 minutes before that. Tottenham won 7 corners in the 18 minutes they trailed West Ham, then none in the 45 minutes they led. Liverpool won 9 corners in the 35 minutes they led Everton, three times as many as in the 62 minutes at level. Raw full-time totals such as 9 to 1 or 12 to 1 hide how much of each team’s count came from the scoreline rather than from its underlying corner strength. The analysis in section 4 corrects for exactly this.

Identifying repeaters

A repeater is a corner that comes straight after another corner by the same team. Repeaters matter because they aren’t statistically independent events: they depend on the corner before them. A team can pick up two or more corners in quick succession, but this is not a fair reflection of their corner-generating strength. Over a small sample of games, a few of these spells can skew a team’s ratings.

Our minute-level event data allows us to identify repeaters. A corner is flagged as a repeater if the previous event in the match was also a corner, taken by the same team, in the same half, and no more than one minute earlier.

4. Analysis

Game state affects corner rates

Teams that are behind attack more, so they win more corners. Teams that are ahead sit deeper and win fewer. The chart shows the home side’s share of all corners in each league, split by the game state at the time.

Home share of corners (%) by scoreline

The size of the effect varies a lot by league: from about 4 points in Scotland Premiership to 26 points in Spain Segunda. Tactical cultures, the prevalence of away fans and the role of dominant teams in each league all play a part in explaining these disparities. Any adjustment has to be league-specific.

Short runs of games distort the picture

If every team’s game state minutes were proportionate to their underlying strength, game state biases would not be present in the raw counts. However, football matches are messy and chaotic and, especially over short samples of games, teams spending disproportionate amounts of minutes in different game states can distort corner rates.

The left panel shows how long each Premier League side should have spent winning, drawing and losing over the first nine games of 2023/24, based on the pre-match lines. The right panel shows how long they actually did.

Several teams spent far more or far less time losing than their strength implied. Their raw corner numbers are inflated or deflated as a result.

Supremacy matters in every game state

Stronger teams win more corners, and that holds whether they’re winning, drawing or losing. To measure it, each league’s team-matches are split into 30 equal-sized buckets by pre-match supremacy, separately for home and away sides. Within each bucket I calculate corners per minute in each game state, then fit a line per state, weighted by the minutes behind each bucket. Pick a league:

Corners per minute vs pre-match supremacy

Each dot is one supremacy bucket, and hovering shows how many minutes are in that bucket. Across all leagues, losing sides win corners fastest and winning sides slowest, and the lines rise with supremacy. Together, the six lines give an expected corner rate for any combination of home/away, game state and supremacy, which drives the adjusted corner values later in this section.

Repeaters are stable across teams

Each dot below is one team, showing the share of its corners that were repeaters (defined in section 3):

Repeater rate by team (teams with 100+ matches)

The rate is stable at around 13–15% across leagues and across teams within each league: 90% of the 310 teams fall between 11% and 16%. So removing repeaters doesn’t penalise any particular style of play. It just removes correlated noise.

Adjusted corner values

Each corner is valued as the average corner rate divided by the rate we’d expect given the context it was won in:

\text{value} = \frac{\text{average rate}_{\text{home/away}}}{\text{expected rate}(\text{home/away},\ \text{game state},\ \text{supremacy})}

A corner won where corners are usually rare (a big underdog, while winning) is worth more than 1. One won where they’re usually plentiful (a big favourite chasing the game) is worth less than 1. Repeaters are worth 0.

Case study: Rayo Vallecano 1–2 Barcelona, 27 August 2024. Barcelona went in as 0.77-goal favourites. Rayo scored in the 9th minute, Barcelona equalised in the 60th and won it with an 82nd-minute goal.

  • Drawing: Rayo corners are worth 1.35 and Barcelona’s 0.81. The gap reflects the difference in team strength alone.
  • Rayo winning: a Rayo corner is worth 1.96, because an underdog protecting a lead rarely wins corners. Barcelona’s are worth 0.62, because a favourite chasing the game is expected to win lots of them.
  • Barcelona winning: the game-state and supremacy effects roughly cancel out, and both sides’ corners are worth close to 1.

Raw corners: 6–6. Adjusted: 5.65–4.29. Once you account for Barcelona chasing the game for more than 50 minutes and three repeaters are removed, Rayo’s corner performance looks clearly better than Barcelona’s.

Buckets, fitted lines and adjusted values → code/adjusted_values.py

Because supremacy is stripped out of each corner’s value, a team’s rating no longer depends much on who it has played. That means shorter rating windows can be used, so changes of manager or personnel show up sooner. It also means promoted and relegated teams carry their ratings between divisions without special handling. The prediction model then adds supremacy back in as a separate input, taken from the upcoming match’s betting lines.

5. Building and testing a predictive model

Do adjusted ratings predict better?

Team attack and defence ratings are built as rolling averages over the last N games, using four metrics:

  • raw: raw corner counts
  • nr: raw counts with repeaters removed
  • adj: adjusted values
  • adj_nr: adjusted values with repeaters removed

Each set of ratings, together with match supremacy, feeds an OLS model that predicts each side’s corners in held-out matches. The chart shows the out-of-sample R² improvement over raw counts, for each window length.

Out-of-sample R², % change vs raw corner ratings

The adjusted metrics beat raw counts at every window length on both sides. The gain is largest for home corners, which are the most sensitive to game state. Removing repeaters from raw counts (nr) makes little difference on its own; almost all of the gain comes from the game-state and supremacy adjustment. The setting carried forward is adj_nr over a 25-game window, the strongest overall (adj is level with it on home corners): home R² 0.113 vs 0.100 raw, and away 0.091 vs 0.087.

R² values of around 0.1 are normal here. Match-level corner counts are dominated by Poisson-like randomness, so no pre-match model explains most of the variance. What matters for betting is whether the model beats the market’s estimate, which is tested next.

Does it beat the market?

The model’s predicted corner supremacy (home minus away) is compared with Pinnacle’s implied corner supremacy for every priced match in 2024/25 and 2025/26. The prediction model is fitted only on earlier seasons, and ratings use only matches played before each fixture. When the two differ by 0.5 corners or more, a 1-unit bet goes on the side the model prefers, at Pinnacle’s price. Every bet is settled on actual raw corners.

Corner handicap ROI by rating set (metric · window)

All 8 adjusted rating sets are profitable in the handicap market, at 2.1–4.1% ROI on 3,206–3,710 bets each, after paying Pinnacle’s margin.

How the edge scales. Raising the minimum disagreement before betting trades volume for conviction. For the adj_nr / 19-game ratings:

Betting every match loses money: Pinnacle is sharp on average. Once the model disagrees by 0.20 corners or more, profit becomes positive. It peaks at 143 units at a 0.50-corner threshold. ROI rises broadly as the threshold tightens, which is the pattern you’d expect if the edge is real. Above about 1.2 corners it gets noisy, because there are only a few hundred bets left. The 0.5 threshold used above was chosen on this same data, so treat the peak as optimistic. The steady rise in ROI is the more reliable evidence.

The totals market is different. The same ratings were backtested against Pinnacle’s corner over/under lines, and every metric/window combination lost money. My working hypothesis is that game state shifts which side wins the corners much more than it changes how many corners there are in total, so correcting for it helps the handicap market and doesn’t help totals.

This is a backtest over roughly two seasons on historical prices. Bets aren’t guaranteed to have been available at those odds or stakes, and results vary by league: some are consistently profitable, others negative. See the methodology page for caveats.

Limitations and next steps

  • Match length is estimated. The source data doesn’t record stoppage time, so match length is taken as the later of 97 minutes and the last recorded event. Better data would improve the minute counts.
  • Other in-game factors aren’t modelled yet. Red cards and the timing of each game state (the effects grow as the match goes on) are obvious next adjustments.
  • Out-of-game factors aren’t modelled either. Manager changes, transfers and end-of-season motivation aren’t captured beyond what the rolling window picks up.
  • No player-level data. Lineup-aware ratings would help with injuries and rotation.
  • Data quality. Some team names are split across different spellings in lower leagues, which affects rolling windows for the teams involved. Three leagues are excluded until they’re given league/tier context.
  • Bet sizing. All backtests use flat 1-unit stakes. Kelly-style sizing based on the size of the disagreement is untested.
